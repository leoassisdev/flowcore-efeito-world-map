## Como instalar

1. **Instale as dependências**

   ```bash
   npm install motion dotted-map
   ```

2. **Crie src/components/WorldMap.tsx** Copie o conteúdo de `src/WorldMap.tsx` deste repositório.
3. **Use na página**

   ```tsx
   <WorldMap dots={[{start:{lat,lng}, end:{lat,lng}}]} lineColor='#3FB5FF' />
   ```
